# LT1

## description
We are using radius to find the area, circumference, square root, rounded up area, and rounded down area of the garden.

## How to run
Just input the radius of the garden, and it will naturally find the area, circumference, square root, rounded up area, and rounded down area of the garden.

# Input needed
The only input needed is the radius of the garden.

# Sample output
Enter the Radius of the garden10

The radius of the garden is 10.0

The area of the garden is 314.16

The circumference of the garden is 62.83

The square root of the garden is 17.72

The rounded down area of the garden is 314.00

The rounded up area of the garden is 315.00
